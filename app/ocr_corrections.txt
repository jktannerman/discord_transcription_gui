# Regex find/replace rules for common Tesseract OCR misreads, applied once
# to each image's freshly-OCR'd text before it becomes a review item's
# starting OCR-box content (see ocr_corrections.py/review_item.build_review_items)
# - never to a box once the user has edited it.
#
# Format: one entry per blank-line-separated block, each block being:
#   <find regex, one line>
#   <replacement, one line - \1 etc. refer to the find regex's capture groups>
#   # any number of comment lines (must start with "#")
# This comment block itself is a free-standing, entry-less comment (every
# line in it starts with "#"), so it's skipped rather than parsed as a
# malformed entry.

\|
I
# Tesseract frequently reads a capital "I" as a bare pipe character.
# Moved here from the old post-finalize cleanup pass (cleanup.py) - this
# is exactly the kind of per-image OCR-misread fix this file is for,
# rather than something that needs to run over the whole output file at
# Finalize time.

\n\n‘(?!(?:(?!\n\n)[\s\S]){0,80}’)
\n\n
# Drops a stray opening curly quote right after a paragraph break, unless
# a matching closing curly quote (') turns up within the next ~80
# characters before the next paragraph break - in which case it's
# probably a real quotation, not an OCR artifact, and is left alone.
# Heuristic, not exact: raise/lower 80 if it's missing or over-matching
# real quotes in practice.

,(\n+)
.\1
# A comma just before a paragraph break should usually be a period.

©
C
# Misread copyright symbol.

\b([A-Z]),
\1.
